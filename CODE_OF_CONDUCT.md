# Code of Conduct

## Our standard

We are committed to making Alpha a welcoming, respectful, and harassment-free project for everyone.

Expected behavior includes respectful communication, constructive feedback, empathy, and collaboration in good faith.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, sexualized conduct, and publishing private information without permission.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when behavior violates this code. Serious incidents should be reported privately to the maintainer through the repository's security/contact channel.

## Scope

This code applies to project spaces and public interactions where someone is representing the Alpha project.
